# 대화 컨텍스트 무결성 보강 계획

## 목표

실패·취소·중단·생성 중인 assistant 메시지가 다음 LLM 요청의 대화 컨텍스트에 다시 포함되지 않도록 한다. 사용자가 실제로 확인할 수 있는 대화 기록은 보존하되, 모델에게 전달하는 작업 컨텍스트와 분리한다.

## 범위

1. 상태별 컨텍스트 포함 정책을 테스트로 고정한다.
2. 완료된 assistant 응답과 사용자 메시지만 기본 컨텍스트에 포함한다.
3. 실패한 응답의 일부 스트림, 취소 안내, 중단된 응답, 아직 생성 중인 응답은 제외한다.
4. 기존 메모리 예산과 대화 순서·API 응답은 변경하지 않는다.
5. 집중 테스트, 전체 EEEE 테스트, 인코딩 검사를 실행한다.

## 완료 조건

- 실패/중단/스트리밍 assistant 본문이 컨텍스트에 포함되지 않는다.
- 사용자 메시지와 완료된 assistant 응답은 순서대로 유지된다.
- 기존 테스트와 새 회귀 테스트가 모두 통과한다.
- 변경 내용이 한국어 PR로 리뷰·CI 확인 후 main에 병합된다.
