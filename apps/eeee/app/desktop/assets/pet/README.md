# EEEE 펫 에셋 표

실제 런타임에서 사용하는 고양이 원본을 덮어쓰지 않고, 화면 합성에 필요한 구성요소를 분리한 표다.

| 구분 | 파일 | 용도 | 상태 변화 |
| --- | --- | --- | --- |
| 공통 몸체 | `../cat-keyboard-idle.png` | 고양이와 키보드의 고정 레이어 | 항상 유지 |
| 왼손 기본 | `paw-left-rest.png` | 논리적 왼손의 대기 상태 | 왼손 배열 키 입력 후 복귀 |
| 왼손 누름 | `paw-left-press.png` | 논리적 왼손의 누름 상태 | 왼손 배열 키 입력 중 |
| 오른손 기본 | `paw-right-rest.png` | 논리적 오른손의 대기 상태 | 오른손 배열 키 입력 후 복귀 |
| 오른손 누름 | `paw-right-press.png` | 논리적 오른손의 누름 상태 | 오른손 배열 키 입력 중 |
| 시선 왼쪽 | `../cat-keyboard-gaze-left.png` | 마우스가 왼쪽에 있을 때 참고 프레임 | 시선 보정 |
| 시선 오른쪽 | `../cat-keyboard-gaze-right.png` | 마우스가 오른쪽에 있을 때 참고 프레임 | 시선 보정 |

전체 시트는 [`pet-asset-table.png`](pet-asset-table.png)에서 확인할 수 있다.

## 합성 규칙

- 몸체·키보드는 `idle`을 공통으로 유지한다.
- 앞발은 입력된 키의 물리적 배열에 따라 한쪽만 교체한다.
- 같은 손의 연속 입력도 몸체 전체를 교체하지 않고 해당 앞발 레이어만 누름 상태로 바꾼다.
- 원본 좌우 파일명은 기존 미러링 자산과의 호환성을 위해 논리 손과 교차될 수 있으므로 `pet_assets.py`의 표를 기준으로 한다.
