# 고양이 실행 시 개인 LLM 자동 시작 설계

## 의도

EEEE 고양이 위젯을 실행하면 별도 터미널에서 `personal-llm`을 먼저 띄우지
않아도 개인 LLM이 대화 요청을 받을 수 있게 한다.

## 목표와 비목표

- 목표: 고양이 런타임 시작 시 loopback 개인 LLM을 재사용하거나 자동 시작한다.
- 목표: EEEE가 직접 시작한 개인 LLM만 고양이 종료 시 정리한다.
- 목표: 개인 LLM이 설치되지 않았거나 시작에 실패해도 고양이 UI 자체는 실행한다.
- 비목표: 윈도우 로그인 시 전역 자동실행을 등록한다.
- 비목표: 외부 주소의 LLM 프로세스를 자동으로 시작하거나 종료한다.

## 제약

- 기본 주소는 `http://127.0.0.1:8765`다.
- 개인 LLM 프로젝트 경로와 실행 파일은 환경설정으로 덮어쓸 수 있어야 한다.
- 기존에 실행 중인 개인 LLM은 소유권을 주장하지 않고 그대로 재사용한다.

## 접근 방식

1. 실행 스크립트만 수정: 수동 실행에는 간단하지만 다른 EEEE 실행 경로와
   packaged desktop을 놓친다.
2. 윈도우 전역 자동실행 등록: 로그인 시에는 편하지만 고양이와 프로세스
   수명이 분리되고 사용자 시스템을 추가로 변경한다.
3. EEEE desktop runtime이 loopback 개인 LLM child process를 관리: 현재
   Ollama/bridge lifecycle 패턴을 재사용하고 모든 고양이 실행 경로에
   적용할 수 있다. 이 방식을 선택한다.

## 동작

`personal_llm` 또는 `auto` provider이고 자동 시작이 켜져 있으면 EEEE는
loopback health를 확인한다. 이미 정상이면 아무것도 실행하지 않는다. 정상이
아니면 설정된 프로젝트 루트에서 `personal-llm`을 실행하고 제한 시간 동안
health를 기다린다. 실패해도 EEEE API와 고양이 UI는 계속 시작하며 runtime
상태에서 개인 LLM unavailable이 보인다.
